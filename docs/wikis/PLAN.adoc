= Wiki plan (berrywiki-shaped, 3-ply / span 7)

GitHub wiki is **off** (estate). Content lives in `docs/wikis/`.
`metadatastician/berrywiki` is a Cargo wiki app — **not vendored**.
This tree follows its audience split, not its Rust runtime.

== Constraints

* Max **3-ply** nesting (`docs/wikis/{audience}/{page}`)
* Max **span 7** at each layer
