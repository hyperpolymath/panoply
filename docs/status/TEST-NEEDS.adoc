the Core, Evidence, and Manifest artefacts described by the charter are not
yet implemented. Test infrastructure at this stage necessarily covers the
Idris2 ABI / Zig FFI scaffold, not language semantics.

== What was removed

The template-distribution machinery that does not apply to an instantiated
downstream repository has been removed:

* `scripts/validate-template.sh` (8-phase template-distribution validator)
* `tests/e2e/template_instantiation_test.sh` (clone-and-substitute E2E test)

`benches/template_bench.sh` had benchmark sections gated on both scripts;
those sections were removed and the remaining benchmarks (Zig build, Zig
test, workflow validation) were kept and renumbered.
