# Users

A Panoply **manifest** lists earned and un-earned envelopes. Today every honest manifest is `:status refused` with empty `:earned`. Silence is not safety.

There is no GUI. There is no `panoply` binary. You read specs and refused examples under `src/manifest/` (those files are AsciiDoc / s-expr, not this wiki).
