# Glossary

- **Envelope** — named guarantee with scope + evidence pointer.
- **Manifest** — per-program, per-backend earned/unearned list.
- **Projection** — surface that elaborates into Core + evidence + manifest, or rejects.
- **Deed** — s-expression metadata (`.deed`). Gatekeeper `0-AI-MANIFEST.deed` is still kv.
- **BerryWiki** — Markdown notebook for GitHub wiki; not the technical docs tree.
