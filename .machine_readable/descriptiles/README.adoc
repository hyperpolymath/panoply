= descriptiles

Canonical live path for STATE / META / ECOSYSTEM / AGENTIC / NEUROSYM /
PLAYBOOK / CLADE (s-expression repo-deeds). The old template name `6a2/`
is **not** used in this repository.

[cols="1,3"]
|===
| File | Role

| `STATE.deed` | phase, milestones
| `META.deed` | ADRs / rationale
| `ECOSYSTEM.deed` | boundaries
| `AGENTIC.deed` | agent constraints
| `NEUROSYM.deed` | composition notes
| `PLAYBOOK.deed` | runbooks
| `CLADE.deed` | clade membership
| `LANGUAGES.deed` | language inventory
| `anchors/` | authority anchors
|===
