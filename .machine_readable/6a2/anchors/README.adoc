# A2ML Anchor Directory

This directory contains ANCHOR.deed files for project recalibration and scope intervention.

## Files

- `ANCHOR.deed` - Project recalibration, scope intervention, canonical authority

## Multiple Versions

Unlike other A2ML files, multiple versions of ANCHOR.deed with different dates may exist.
Each version represents a specific recalibration point in the project history.

## Standards Compliance

These files follow the ANCHOR.deed specification from:
https://github.com/hyperpolymath/standards/tree/main/anchor-a2ml
