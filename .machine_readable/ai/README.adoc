= AI Guidance Directory

Put AI-facing instructions in this folder.

Examples:

* `CLAUDE.md`
* `COPILOT.md`
* `GEMINI.md`
* `AI.deed`
* `AI.djot`

Avoid scattering agent instruction files around the repo root.

Recommended machine read order:

* `.machine_readable/descriptiles/anchors/ANCHOR.deed`
* `.machine_readable/policies/MAINTENANCE-AXES.deed`
* `.machine_readable/policies/MAINTENANCE-CHECKLIST.deed`
* `.machine_readable/policies/SOFTWARE-DEVELOPMENT-APPROACH.deed`
* `.machine_readable/descriptiles/STATE.deed`
* `.machine_readable/descriptiles/META.deed`
