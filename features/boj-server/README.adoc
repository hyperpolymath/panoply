= BoJ Server — holding (not a cartridge)
:icons: font

Panoply is **not** a BoJ host and does **not** ship a cartridge.

Canonical registry:
https://github.com/hyperpolymath/boj-server-cartridges

Hosts (`boj-server`, panll) fetch cartridges from that registry. This
directory exists so the RSR feature slot is occupied with an honest
decline, not a fake integration.

Phase 8: consume a registry cartridge if a Core checker needs a BoJ
capability. Do not vendor cartridge source here.
