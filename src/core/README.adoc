= Core (sketch)
:icons: font

[.lead]
The *checked Core*: the single target into which every accepted Panoply program
projects. All guarantees are reasoned about here — never in a surface syntax.

[IMPORTANT]
====
*Checker not yet implemented.* The *specification* of syntax and judgements
is in this directory (issue #5). No executable Core checker exists; per the
charter this README asserts no guarantee it cannot witness.
====

== Specified here

* xref:CORE-SYNTAX.adoc[CORE-SYNTAX.adoc] — abstract syntax (terms, types,
  usage quantities, affine fragment).
* xref:CORE-JUDGEMENTS.adoc[CORE-JUDGEMENTS.adoc] — checking judgements and
  the facts a successful check establishes. A check *yields evidence* `E`,
  not a boolean.

== What will live here (implementation)

* The interface every projection elaborates *into* and every backend lowers
  *from*.
* An executable checker that constructs `E` (blocked on issue #6 formats).

== Obligations

* Core is the *only* place guarantees are established; a surface feature that
  cannot be expressed/constrained in Core cannot be guaranteed.
* A successful check yields *evidence* (see `../evidence/`), not just a pass/fail.
* Core makes no global safety claim — it produces the facts that envelopes name.
